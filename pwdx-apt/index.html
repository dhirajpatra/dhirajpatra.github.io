pwdx apt repository

Stateless, offline password derivation. Debian and Ubuntu (22.04 or newer). Current version: 0.1.0-1.

Install

sudo install -d -m 0755 /usr/share/keyrings
curl -fsSL https://dhirajpatra.github.io/pwdx-apt/pwdx-archive-keyring.gpg | sudo tee /usr/share/keyrings/pwdx-archive-keyring.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/pwdx-archive-keyring.gpg] https://dhirajpatra.github.io/pwdx-apt ./" | sudo tee /etc/apt/sources.list.d/pwdx.list
sudo apt update
sudo apt install pwdx-cli

Then run pwdx-cli selftest. Updates arrive through sudo apt update && sudo apt upgrade.

Verify the signing key

Fingerprint: 3D93F64918CBBD3B580A4418D52F43A7C1D85283

gpg --show-keys --fingerprint /usr/share/keyrings/pwdx-archive-keyring.gpg

Compare it with the fingerprint published in the project README.
